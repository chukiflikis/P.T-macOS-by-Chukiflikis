# P.T-macOS-by-Chukiflikis
## INSTALLATION
1. Drag “P.T..app” into the “Applications” folder.
2. Launch the app from Applications.
3. On first launch, select your own CUSA01127 folder, which must contain “chunk1.psarc” and “texture.qar”. The app only reads these files; it does not modify them.

## REQUIREMENTS
- Mac with Apple Silicon (M1 or later).
- macOS 14 or later.
- Your own extracted copy of P.T. (CUSA01127). No game files are included.

## SAVE DATA
Save files, settings, logs, and cache are stored in:
`~/Library/Application Support/org.ptpc.mac.guardado/`

## SECURITY
This version is locally code-signed but has not been notarized by Apple. After downloading, macOS may require you to confirm the first launch by right-clicking the app in Finder and selecting “Open”.

Do not disable macOS system-wide security protections.

## CURRENT STATUS
Frame generation remains disabled for stability and safety reasons. MetalFX Spatial and FSR 2.2 are available in the graphics settings when supported by your hardware.
