# P.T-macOS-by-Chukiflikis

INSTALACIÓN
1. Arrastra “P.T..app” a la carpeta “Aplicaciones”.
2. Abre la app desde Aplicaciones.
3. En el primer inicio, selecciona tu propia carpeta CUSA01127, que debe contener
   “chunk1.psarc” y “texture.qar”. La app solo lee esos archivos; no los modifica.

REQUISITOS
- Mac con Apple Silicon (M1 o posterior).
- macOS 14 o posterior.
- Una copia extraída propia de P.T. (CUSA01127). No se incluye ningún archivo del juego.

GUARDADO
Las partidas, ajustes, registros y caché se guardan en:
~/Library/Application Support/org.ptpc.mac.guardado/

SEGURIDAD
Esta beta está firmada localmente, pero no notarizada por Apple. Tras descargarla,
macOS puede pedir confirmar la primera apertura desde Finder con clic secundario > Abrir.
No desactives las protecciones globales de macOS.

ESTADO
La generación de fotogramas permanece desactivada por seguridad. MetalFX Spatial y
FSR 2.2 están disponibles desde los ajustes gráficos cuando el equipo los admita.

P.T. pertenece a Konami. Esta distribución no incluye contenido del juego.
